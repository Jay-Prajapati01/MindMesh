# Code of Conduct

MindMesh is a community project. Everyone participating in its issues, pull
requests, discussions, and other project spaces is expected to help keep them
welcoming and constructive.

## Expected behavior

- Be respectful and focus criticism on ideas and work, not people.
- Assume good intent, communicate clearly, and welcome different perspectives.
- Keep feedback relevant, actionable, and appropriate for a public project.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, and repeated
disruptive or abusive behavior are not acceptable. Do not publish another
person's private information or use project spaces for spam.

## Enforcement

Project maintainers may edit or remove content, close discussions, or restrict
participation when necessary to maintain a safe and useful community space.
Report conduct concerns privately to the project maintainer through the
[maintainer's GitHub profile](https://github.com/Jay-Prajapati01).
